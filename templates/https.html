You are on {{ 'HTTPS' if on_https else 'HTTP' }} now. The machines push punches over plain HTTP - that keeps working when HTTPS is switched on for people.

1. Remove the browser warning (once per PC / phone)

The server has its own small certificate authority. Install it once and the browser shows the padlock with no warning - also when the server's IP address changes later.

Windows PC (Chrome, Edge, Firefox):

Download installer (.bat)

Double-click it and click Yes (it needs Administrator). Or by hand: download the certificate → double-click → Install Certificate → Local Machine → Place all certificates in: Trusted Root Certification Authorities → Finish. Many PCs at once: IT can push the same .crt with Group Policy, or run certutil -addstore -f Root LailaPayroll-CA.crt.

Android phone: open http://{{ host }}:{{ port }}/https/ca.crt in Chrome → Settings → Security → Install a certificate → CA certificate → choose the downloaded file.

iPhone: open the same link in Safari → Settings → Profile downloaded → Install → Settings → General → About → Certificate Trust Settings → turn it on.

Without installing it everything still works - the browser just shows "Not secure / Your connection is not private" once; click Advanced → Continue.

2. Use HTTPS for everyone

Old bookmarks keep working - they are forwarded. Switch it on only after checking the HTTPS address opens on this PC.
